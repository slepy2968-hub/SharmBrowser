# Sharm

Минималистичный браузер для Windows 10/11 x64. Нативная оболочка WPF, движок Microsoft Edge WebView2. Стартовая страница не создаёт веб-движок до первого перехода. Поиск — Google.

## Запуск

`release\Sharm.exe` — автономная сборка, установка .NET не нужна. Нужен Microsoft Edge WebView2 Runtime, обычно уже установленный в Windows. При отсутствии: https://developer.microsoft.com/microsoft-edge/webview2/

## Возможности

- Ровный тёмный фон без градиентов, компактный поиск 480×48, мягкая прозрачная поверхность с тонкой равномерной окантовкой. Размытие однотонной подложки убрано, чтобы не создавать лишние графические поверхности. Без слоганов, подписи Google, подсказок клавиш и нижней строки состояния.
- Встроенные SF Pro Display Semibold для названия Sharm и SF Pro Text для интерфейса. Файлы скачаны из https://github.com/sahibjotsaggu/San-Francisco-Pro-Fonts; установка шрифтов в Windows не нужна.
- Под поиском шесть иконок сайтов без подписей. Частые посещения поднимаются первыми, свободные места дополняются закладками и стартовыми сайтами. Наведение плавно поднимает иконку и соседние; системное отключение анимаций учитывается. Правая кнопка — открыть в новой вкладке или скрыть.
- Подсказки в адресной строке и на главной: открытые вкладки, закладки, история и поисковые подсказки Google. Выбор мышью или стрелками, Enter открывает, Escape закрывает. Без сети остаются локальные подсказки. Поисковые подсказки загружаются после паузы 220 мс; адреса с точкой и URL не отправляются в сервис поисковых подсказок.
- Иконки сайтов загружаются из Google favicon service и кэшируются в `%LOCALAPPDATA%\Sharm\Icons`. История сохраняется целиком в локальном файле сессии.
- Адреса и поисковые запросы в одной строке. Строка на главной странице без иконок.
- Cookies, разрешения сайтов, автозаполнение, закладки и список вкладок сохраняются в `%LOCALAPPDATA%\Sharm`.
- При первом запуске новой версии однократно переносятся закладки, полная история и обычные cookies Firefox. Вкладки Firefox не переносятся. Данные сохраняются в собственном профиле Sharm, отметка завершения предотвращает повторный импорт при последующих запусках. Повторный перенос доступен вручную через настройки. Сессионные cookies сохраняются с шифрованием Windows для текущего пользователя перед выгрузкой страниц и закрытием. Выход с сайта обновляет сохранённое состояние. Срок действия входа по-прежнему определяется сайтом.
- Cookies Firefox, разделённые между сайтами ради приватности, пропускаются: движок Sharm не умеет сохранить Firefox partition key. Выбранный профиль Firefox не содержит сохранённых паролей; менеджер паролей WebView2 нельзя заполнить через доступное API.
- Восстановление вкладок после перезапуска: страницы загружаются только при выборе.
- Экономия памяти включена по умолчанию: загружена только выбранная обычная страница, фоновая выгружается сразу при переключении. Исключения: аудио, текущие загрузки, закреплённые вкладки и формы, в которых введены данные. Выгруженная страница открывается заново при выборе. Сохраняются позиция прокрутки и время основного видео; восстановление позиции видео зависит от готовности плеера сайта.
- В настройках есть ручная выгрузка фоновых страниц и память всех процессов Sharm, включая WebView2. Считается private working set: физически резидентная личная память, без повторного суммирования общих DLL. На старой Windows, где расширенный счётчик недоступен, используется обычный working set. При выключенной экономии таймер — 10 минут, кэш — до шести страниц. Ограничения не прерывают аудио, загрузки и редактирование форм.
- JavaScript-движок запускается с `--optimize-for-size`, чтобы отдавать приоритет размеру кода и памяти. Без жёсткого ограничения JS-кучи, отключения sandbox или принудительного вытеснения в файл подкачки.
- Лёгкий YouTube включён по умолчанию: ссылки на видео открываются в официальном встроенном плеере без комментариев и рекомендаций. Кнопка «Полная страница» возвращает обычный сайт. Для видео, запрещённых к встраиванию, полная страница открывается автоматически. Режим отключается в настройках. У главной и поиска YouTube остаётся обычный интерфейс сайта.
- Создание новых веб-страниц проходит по очереди. Если быстро открыть много ссылок, страницы, переставшие быть выбранными, остаются только записями вкладок. Звук, загрузки и несохранённые формы по-прежнему защищены от выгрузки.
- Шапка поддерживает перемещение окна за название и свободную область рядом с вкладками, восстановление при перетаскивании из развёрнутого состояния и Windows Snap. Двойной щелчок разворачивает/восстанавливает, правая кнопка показывает системное меню.
- Заголовки вкладок виртуализированы: элементы вне видимой области не создаются. Сохранение сессии объединяет изменения за 600 мс и пишет JSON потоком. История закрытых вкладок ограничена двадцатью записями.
- Коллекция вкладок уведомляет интерфейс об изменениях сразу, поэтому быстрое открытие и закрытие вкладок не рассинхронизирует виртуализированный список. Иконки главной обновляются только при изменении набора сайтов; кэш иконок ограничен 32 сайтами.
- Предел 100 МБ для браузера с активным YouTube не обеспечивается: браузер, рендереры и видеодекодер движка расходуют память независимо. Фиктивного ограничения через принудительное вытеснение памяти в файл подкачки нет.
- Собственные тёмные окна настроек и загрузок: переключатели, карточки разделов, единое меню и прокрутка. Загрузки открываются автоматически и через Ctrl+J: прогресс, пауза, продолжение, отмена, открытие файла и показ в папке. Список сохраняется до закрытия браузера; очистка завершённых не удаляет файлы.
- Масштаб, стандартное контекстное меню страницы, разрешения камеры и микрофона с подтверждением.
- Закладки доступны через меню и участвуют в подборе иконок. Звезда у адресной строки добавляет или удаляет текущую страницу.

## Клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+L | Адресная строка |
| Ctrl+T / Ctrl+W | Создать / закрыть вкладку |
| Ctrl+Shift+T | Вернуть закрытую вкладку |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующая / предыдущая вкладка |
| Alt+← / Alt+→ | Назад / вперёд |
| Alt+Home | Новая стартовая страница |
| Ctrl+R / F5 | Обновить |
| Ctrl+D | Добавить / удалить закладку |
| Ctrl+J | Все загрузки браузера |
| Ctrl++ / Ctrl+− / Ctrl+0 | Масштаб |
| F11 | Развернуть / восстановить окно |

## Сборка

Нужны Windows и .NET 10 SDK. Выполнить `./build.ps1`, либо `./build.ps1 -Run`. WebView2 SDK восстанавливается через NuGet. Движок обновляется установленным WebView2 Runtime.

Один экземпляр приложения управляет профилем: повторный запуск показывает уже открытое окно. Открытые вкладки и выбранная вкладка сохраняются сразу после изменений и восстанавливаются при следующем запуске.

`Sharm.exe --self-test` использует отдельный тестовый профиль, проверяет адреса, Google, HTTPS, cookies, переключение и закрытие вкладок, сохранение сессии. Результат: `%LOCALAPPDATA%\Sharm\self-test.txt`; изображение стартовой страницы: `preview.png` в той же папке.

`Sharm.exe --self-test --memory-benchmark` замеряет главную, воспроизведение YouTube без звука и сто сохранённых вкладок. Используется отдельный профиль BenchmarkProfile; личная сессия не изменяется. Отчёт: `%LOCALAPPDATA%\Sharm\memory-benchmark.json`. Метрики относятся к конкретному запуску и не являются пределом памяти.

Повторный запуск с `--self-test --verify-cookie --verify-session` дополнительно проверяет сохранение cookies, списка вкладок, адресов и активной вкладки между отдельными процессами приложения.

Это первая версия браузерной оболочки: без расширений Chrome, синхронизации и собственного менеджера обновлений. Некоторые провайдеры входа и DRM-сервисы ограничивают встроенные браузеры. Память зависит от открытых сайтов; фиксированный лимит не задаётся.

Документация движка: https://learn.microsoft.com/microsoft-edge/webview2/concepts/performance
